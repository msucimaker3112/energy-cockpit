Energy-CockpitEnergiefluss, Geräte & Verbrauch und Statistik für Home Assistant

Version 0.1.2

1. Installation mit HACS

  1. HACS öffnen → ⋮ → Benutzerdefinierte Repositories
  2. Repository eintragen:
    https://github.com/msucimaker3112/energy-cockpit
  3. Kategorie Dashboard wählen → Hinzufügen
  4. "Energy-Cockpit" suchen → Herunterladen
  5. Browser-Cache leeren: Strg + F5

2. Ohne HACS

  1. energy-cockpit.js aus dem Release in config/www/ kopieren
  2. Einstellungen → Dashboards → ⋮ → Ressourcen:
    URL /local/energy-cockpit.js, Typ JavaScript-Modul
  3. Strg + F5

3. Karte hinzufügen

  1. Dashboard → Bearbeiten → Karte hinzufügen
  2. Nach Energy-Cockpit suchen, Karte wählen
  3. Sensoren im Editor auswählen → Speichern
Für Wandtablets: Ansicht vom Typ Panel verwenden.

Die drei Karten

KarteZeigt
energy-cockpit-flow-cardEnergiefluss: Solar, Netz, Batterie, Haus, Verbraucher, Überschuss
energy-cockpit-devices-cardRäume und Geräte mit Live-Leistung, Kosten, Standby
energy-cockpit-stats-cardErsparnis, Autarkie, Amortisation, Grundlast, Monatsvergleich

Minimalkonfiguration (Energiefluss)

type: custom:energy-cockpit-flow-card
pv:
  entity: sensor.pv_leistung
grid:
  entity: sensor.netz_leistung
battery:
  power: sensor.batterie_leistung
  soc: sensor.batterie_ladestand
grid_price: input_number.strompreis

Häufige Probleme

ProblemLösung
Karte nicht in der ListeRessource prüfen (Typ Modul), Strg + F5
Netz: Bezug als EinspeisungVorzeichen umkehren beim Netz
Keine Kosten sichtbargrid_price konfigurieren
Werte zeigen "—"Sensor nicht verfügbar oder keine W/kW-Einheit
Statistik leerZähler brauchen state_class und Langzeitstatistik
Tipp: Einzelverbraucher und Gruppen wählst du im grafischen Editor. Abfallkalender und Überschussvorschläge gibt es nur im YAML-Editor. Der grafische Editor behält sie beim Speichern bei.
